# DC Psicólogos

A responsive corporate website developed for a psychology practice located in Madrid, Spain.

The project focuses on providing an accessible and user-friendly experience for potential patients, allowing them to explore psychological services, meet the professional team, read informative articles, and request appointments through a contact form.

---

## Overview

DC Psicólogos is a multi-page website designed to present professional psychological services in a clear, modern, and approachable way.

The website was developed with a strong focus on:

- User experience (UX)
- Responsive design
- Accessibility
- Information architecture
- Performance optimization
